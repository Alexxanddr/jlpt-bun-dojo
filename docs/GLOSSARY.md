# Glossary

| Term | Meaning |
| --- | --- |
| JLPT N5 / 日本語能力試験N5 | Introductory exam level used as a scope target; no official exhaustive lists exist. |
| prompt / traccia | Italian or English meaning the learner must express in Japanese. |
| reference / frase di riferimento | Hidden reviewed or generated Japanese rendering of the same prompt. |
| deterministic finding / controllo verificabile | Reproducible local observation owned by server code. |
| scope finding / limite del dataset | A local-list absence; evidence about coverage, not correctness. |
| AI suggestion / suggerimento AI | Probabilistic model judgment that cannot become a hard local error. |
| grammar point / punto grammaticale / 文法項目 | Reviewed teaching unit with stable ID, category, descriptions, and pattern. |
| lemma / forma dizionario / 辞書形 | Sudachi dictionary form used for membership and similarity. |
| NFKC | Unicode normalization applied before tokenization. |
| Sudachi | Japanese morphological analyzer using SplitMode A in this project. |
| SM-2 | Spaced-repetition state machine storing repetitions, interval, ease, and due time. |
| due review / ripasso in scadenza | Earliest scheduled sentence whose due timestamp has passed. |
| cram / ripasso intensivo | Practice of scheduled material without changing its schedule. |
| grammar journal / quaderno grammaticale | Latest actionable result grouped by grammar point. |
| targeted practice / punti deboli MCP | AI generation constrained by admitted Bunpro/WaniKani weaknesses. |
| MCP | Model Context Protocol; used here only through fixed administrator-run stdio tools. |
| OpenAI-compatible | Configurable local or remote Chat Completions endpoint using the same wire shape. |
| strict JSON Schema | Provider response contract with required typed fields and no extra properties. |
| reviewed | Human-curated project/source data; AI-generated sentences are explicitly unreviewed. |
